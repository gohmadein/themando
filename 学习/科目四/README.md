## 答题核心要点

- **安全文明底层逻辑**：一切以“安全、减速、礼让、提前预判”为最高准则；遇到行人、校车、非机动车或视线受阻路口，优先选择减速或停车让行。
- **高频易错场景**：重点留意**高速爆胎/故障处置（紧握方向盘、轻踩或点刹减速，切勿急踩死刹车或猛打方向）**、**下长坡控制车速（利用发动机制动）**、**涉水行车与湿滑路面侧滑修正**以及**伤员救护常识**。
