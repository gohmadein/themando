## 分卷还原

超过单个附件大小限制的压缩包按字节分卷保存。先下载同一文件的全部分卷，放在 `manifest.json`、`restore.py` 同一目录，安装 Python 后执行：

```powershell
py -3 restore.py
```

脚本按顺序合并分卷，恢复原始文件名并核对 SHA-256。完整下载、恢复并校验后即可正常解压。

完整文件清单、原始大小和 SHA-256 见 [manifest.json](manifest.json)。
