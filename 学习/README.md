## 大文件下载与还原

较大的文件按字节分卷保存。先下载所需文件的全部分卷，放在 `manifest.json`、`restore.py` 同一目录，安装 Python 后执行：

```powershell
py -3 restore.py
```

如果已安装并登录 GitHub CLI，可在保存上述两个文件的目录中一次下载本次全部附件：

```powershell
gh release download study-materials-20261014 --repo gohmadein/themando
py -3 restore.py
```

脚本按顺序合并分卷（或复制未分卷的附件），恢复原始文件名和目录，并核对 SHA-256。完整下载、恢复并校验后即可正常解压。缺少附件的文件会跳过，已存在且校验一致的文件不会重复生成。

完整文件清单、原始大小和 SHA-256 见 [manifest.json](manifest.json)。
