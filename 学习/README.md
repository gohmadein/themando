## 大文件分卷下载与一键还原

体积较大的课程压缩包按字节分卷保存在 Releases 中。只需将目标文件的全部分卷下载至 [`manifest.json`](manifest.json) 与 [`restore.py`](restore.py) 所在目录，安装 Python 3 后执行：

```powershell
py -3 restore.py
```

若已安装并登录 GitHub CLI（`gh`），可在保存 `manifest.json` 与 `restore.py` 的目录中批量拉取附件并自动还原：

```powershell
gh release download study-materials-20261014 --repo gohmadein/themando
py -3 restore.py
```

> **校验机制**：`restore.py` 会自动按序号合并分卷（或复制单文件附件）、恢复原始中文文件名及目录结构，并逐一比对 [`manifest.json`](manifest.json) 中的原始字节大小与 **SHA-256** 哈希值；未下载的分卷会自动跳过，已还原且校验通过的文件不会重复写入。
