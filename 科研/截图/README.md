# 科研与学习高效截图工具（Snipaste）

日常阅读英文文献、推导数学公式、复现代码与整理实验结果的高频桌面效率利器：**[Snipaste](https://zh.snipaste.com/)**。

- **官方下载**：[https://zh.snipaste.com/](https://zh.snipaste.com/)（支持 Windows 与 macOS）

---

## 核心亮点与科研妙用

1. **屏幕悬浮贴图（`F3`）**：把论文中的符号表、核心架构图、长公式或 Baseline 对比表截取后置顶固定在屏幕角落，边看边写代码或改论文，彻底告别在多个 PDF 页码与 IDE 之间来回切换。
2. **像素级精确框选与取色**：自动吸附界面元素边界，截图时按 `C` 键一键复制光标处像素的 HEX / RGB 色值，科研绘图提取优秀论文配色极其方便。
3. **剪贴板文本/图像直转贴图**：复制一段超参数配置、终端报错信息或色号后按 `F3`，即可将其变成悬浮便签。
4. **轻量无广告的标注体验**：提供箭头、矩形、序号标尺、荧光笔、马赛克与文字批注，适合组会即时讨论与实验记录留存。

## 常用快捷键速查

| 快捷键 | 操作功能 | 科研/学习高频场景 |
| --- | --- | --- |
| `F1` | 启动截图 | 框选论文公式、实验曲线或终端输出并添加批注 |
| `F3` | **悬浮贴图到桌面顶层** | 对照论文伪代码编写模型、跨表比对多组实验指标 |
| `Shift + F3` | 隐藏 / 恢复全部贴图 | 临时查看被贴图遮挡的底层代码窗口 |
| `C`（截图时） | 复制当前像素色值（`Shift` 切换格式） | 提取顶刊图表配色应用到 Matplotlib / 绘图脚本 |
| `滚轮` / `Ctrl + 滚轮` | 缩放贴图尺寸 / 调节贴图透明度 | 将参考图缩放停靠在屏幕边缘 |
| `双击贴图` 或 `Esc` | 销毁当前贴图 | 完成对照后一键清理屏幕 |
