# 英文学术论文写作与叙事优化（Anti-Defensive Writing）

收录英文学术论文全生命周期写作与改稿技能 **[`anti-defensive-writing-en/`](anti-defensive-writing-en/SKILL.md)**，核心理念为 **“论文即新闻发布会（The Press-Release Principle）”** —— 帮助作者彻底告别自我矮化、流水账式实验日志与防御性写作，围绕最具发表价值的核心优势构建最有说服力的学术叙事。

---

## 核心理念与解决痛点

许多初稿或 AI 润色稿容易陷入**防御性写作（Defensive Writing）**：平均用力罗列所有做过的工作、过早暴露次要指标短板、用消极词汇自我削弱，甚至替审稿人制造攻击靶点。本指南与 AI 技能旨在贯穿**初稿撰写、摘要/引言重构、实验组织、篇幅精简与审稿回复（Rebuttal）**全阶段：

- **只围绕核心长板组织主线**：识别工作真正领先、独特或不可替代的价值（新机制、新问题定义、更低成本、更优可扩展性或更合理的工程权衡），不构成优势的内容不进主线。
- **拒绝实验流水账**：摒弃“先试了 X，又试了 Y，Z 失败了”的过程汇报，保持严密的论证闭环：**问题为何重要 → 现有方法核心缺口 → 本文方法机制 → 实验证据如何支撑**。
- **绝不预设必输战场**：不在非核心弱势指标上硬碰硬，而是精确界定任务边界、适用场景与评价维度，清晰阐明优势产生的条件与原因。
- **杜绝自我矮化措辞**：禁用 `unfortunately`、`merely`、`only achieves`、`limited improvement` 等自损表达；局部现象绝不上升为对整体方法的否定。
- **实验服务于论点**：每一组实验都必须承担明确职责（验证有效性、归因核心模块、证明目标场景价值或排除替代解释），果断删减或弱化分散注意力的冗余表格。

## 投稿前 8 项关键自查清单（Pre-Submission Checklist）

在定稿或提交前，逐句检视以下问题（**绝不主动递刀给审稿人**）：

1. 这句话是否悄悄扩大了本文必须承担的证明责任？
2. 是否主动挑起了原本没人追问的争议问题？
3. 是否把特定条件下的局部现象写成了方法的普遍缺陷？
4. 是否使用了超出实验证据范围的负面定性表述？
5. 段落是否退化成了“我们先做了什么、后做了什么”的工程日志？
6. 是否把并非本文强项的次要指标摆在了主战场位置？
7. 摘要前五句话内，是否已经同时立住了**核心问题**与**本文贡献**？
8. 结论段末尾是否突然塞入了新的自我否定或发散式局限性？

## 快速使用方法

1. **作为 AI 写作/润色 Skill 调用**：将 [`anti-defensive-writing-en/`](anti-defensive-writing-en/) 复制到项目的 `.agents/skills/`、`.claude/skills/` 或 `.codex/skills/` 目录中，在让 AI 润色摘要、重构 Introduction、裁剪篇幅或撰写 Rebuttal 时会自动激活。
2. **人工改稿对照手册**：直接打开 [`SKILL.md`](anti-defensive-writing-en/SKILL.md)，对照其中的 **Default Decision Rules（不利实验材料 7 步处理策略）** 重排图表与论述重心。
