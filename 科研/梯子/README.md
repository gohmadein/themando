# 科研网络与国际学术检索备忘

整理用于日常访问 Google Scholar、arXiv、GitHub、Hugging Face 及参与国际学术会议的网络节点与分流备忘。

---

## 节点服务记录

### 日常稳定节点（文献检索与代码拉取）
- [LibCyberX](https://cn.libcyberx.com/) — 适用于日常外文文献查阅、代码仓库克隆与开发文档浏览
- [OKZ8](https://okz8.me/) — 多地区备用节点，适合多终端日常稳定分流

### 进阶网络环境（纯净住宅 IP）
- [ResIP](https://resip.net/?r=NNW9TB) — 提供高纯净度住宅网络环境，适合对 IP 质量与区域一致性要求较高的海外学术及 AI 平台

---

## 使用建议

- **开启规则分流（Rule Mode）**：将国内高校开源镜像站（清华 TUNA、阿里源等）与校园网/内网地址配置为直连（`DIRECT`），既保证海外学术站点连通性，又不影响国内高速下载。
- **Git / 终端加速**：遇到终端 `git clone` 或权重下载缓慢时，可按本地客户端监听端口配置代理或结合 `uv` 国内镜像源使用。
