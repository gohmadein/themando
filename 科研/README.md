## 推荐科研提效工作流

1. **环境初始化**：使用 [`uv`](uv使用教程/README.md) 创建隔离 Python 环境并锁定依赖版本，确保本地与远程实验环境一致。
2. **智能编码与调试**：借助 [`AI`](AI/README.md) 中的 Orca 编排编码智能体推进代码实现；若体感输出质量波动，先看一眼 ModelTrace 排查模型状态。
3. **实验阅读与超参调优**：阅读参考文献时用 [`截图`](截图/README.md)（Snipaste `F1` + `F3`）把核心公式贴在屏幕一角对照实现；模型训练阶段接入 [`调参`](调参/README.md)（Optuna）自动搜索超参数。
4. **成果汇报与论文打磨**：使用 [`PPT`](PPT/README.md) 的 Beamer 模板生成组会展示 PDF；成文后对照 [`审稿`](审稿/README.md) 中的审稿人视角检视实验基线与结论边界。
